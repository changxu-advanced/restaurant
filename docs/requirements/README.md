# Requirements index

実装上の優先順位はルートの `AGENTS.md` と以下の文書で管理する。

## MVP

- 今日の営業ボード
- 半月希望、30分単位のシフト、ポジション配置
- 労務Rule Set、工時警告、公開禁止条件
- 欠員支援カード
- 在庫状態、欠品予測、発注Draft
- 従業員、技能、新人教材
- 店舗チャット、交換、引き継ぎ
- POS CSV、現金実査、日次締め
- 日本語、簡体字中国語、英語
- 色覚サポート

## Operation targets

- 希望提出: 2分以内
- 欠員支援回答: 2 tap以内
- 写真付き引き継ぎ: 30秒以内
- 通常在庫確認: 3分以内
- 通常締め: 10分以内
- 日常操作の80%以上: キーボード不要

## Out of scope for v0.1

- Customer harassment
- Reservation / no-show
- Equipment maintenance workflow
- Allergen management
- Cross-store support
- Full employee evaluation

これらはPilot結果を基にIssue化し、先行実装しない。
