# 阶段版本说明：员工管理与多语言前端

**日期：2026-10-28**  
**阶段：员工管理功能阶段版**

## 本阶段目标

在原有餐饮运营看板基础上，加入可观察、可编辑的员工管理流程，并将员工状态、工时和技能信息纳入统一的多语言展示体系。

## 已完成的功能

### 员工管理

- 员工卡片列表、搜索和在籍状态筛选。
- 员工详情页，展示基本资料、合同、工时、技能、培训和希望时间段。
- 员工信息编辑与自动保存，重新打开页面可恢复已填写内容。
- 员工新增、停用、休职、复职和退职展示流程。
- 休职员工显示当前无出勤；退职员工保留历史工时但不参与当前工时判断。
- 正社员、特定技能、普通兼职和留学生使用不同的工时展示口径。
- 留学生严格显示每周 28 小时／长假 40 小时限制，并计入兼业工时。
- 普通兼职使用店内合同参考工时，不误显示留学生 28 小时硬上限。
- 员工详情页包含周一至周日出勤柱状图、时间段和工时状态说明。
- 新增 20 名边界 Mock 员工，总计 36 名，用于观察加班、超限、资料缺失、休职和退职等情况。

### 多语言与展示层

- 支持日语、简体中文、繁体中文、英语、韩语和越南语。
- 数据层可以继续保留日文岗位和技能原值，前端根据当前语言统一转换。
- 岗位、技能、培训状态、劳动规则、雇佣状态和可用时间段不再直接显示内部枚举。
- 未知系统标签显示当前语言的“未登记”类文案；员工姓名、备注等自由输入内容保留原文。
- 回到顶部按钮按当前语言显示，英语和越南语按单词竖向排列。
- 日期按日本时区 `Asia/Tokyo` 动态显示，不再使用固定日期。

### 前端与代码整理

- 保持员工卡片、详情页、图表和状态徽章的现有样式与交互。
- 清理未使用的员工展示模块、格式化函数、重复翻译覆盖和旧权限提示键。
- 将员工展示映射集中到 `employeePresentation.ts`，删除未被引用的出勤组件，减少主页面重复代码。
- 保留现有 API Hook、Mock 数据和页面级加载结构，未改变后端数据契约。

## 当前阶段边界

- 本阶段重点是前端功能逻辑、展示和 Mock 数据验证。
- 后端接口、认证角色和生产权限仍需后续联调确认；本说明不代表生产环境权限已经最终定稿。
