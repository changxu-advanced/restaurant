# 段階リリース記録：従業員管理機能と多言語フロントエンド

**日付：2026年10月28日**  
**リリース段階：従業員管理機能ステージ版**

## 概要

既存の飲食店オペレーション画面に、従業員情報・契約・勤務時間・在籍状態を管理するための機能を追加した。店舗内で使用する日本語の職種・スキル値をデータ層に保持し、画面表示時に選択中の言語へ変換する構成とした。

## 実装した機能

### 従業員管理

- 従業員カード一覧、検索、在籍状態フィルターを追加。
- 従業員詳細画面で基本情報、契約、勤務時間、スキル、研修、希望時間帯を確認可能にした。
- 従業員情報の編集と自動保存に対応。画面を再度開いた場合も入力済みの内容を復元する。
- 従業員の新規登録、退職、休職、復職の表示・操作フローを追加。
- 休職中の従業員は「現在の出勤なし」と表示し、退職者は過去の記録を残しながら現在の勤務時間判定から除外する。
- 正社員、特定技能、一般アルバイト、留学生アルバイトで勤務時間の表示ルールを分離。
- 留学生アルバイトは週28時間、長期休暇中は週40時間を上限として、他店・他社の申告時間も合算する。
- 一般アルバイトは留学生向けの28時間上限を適用せず、店舗の契約参考時間として表示する。
- 従業員詳細画面に月曜日から日曜日までの出勤状況、勤務時間帯、勤務ステータス説明を表示。
- 正常勤務、上限接近、上限超過、兼業時間、資料未登録、休職、退職を確認できる36名分のMockデータを用意。

### 多言語表示

- 日本語、簡体字中国語、繁体字中国語、英語、韓国語、ベトナム語に対応。
- データベース側では日本語の職種・スキル値を維持し、フロントエンドの翻訳マッピングで表示言語を切り替える。
- 職種、スキル、研修ステータス、労務ルール、雇用区分、在籍状態、希望時間帯を共通の表示変換で処理。
- 未知のシステム値は内部コードや日本語原値をそのまま表示せず、各言語の「未登録」相当の文言に変換。
- 従業員名、メモ、特徴などの自由入力値は原文を保持。
- ページ上部の日付は日本標準時（`Asia/Tokyo`）で実行時に生成し、固定日付を廃止。
- 「トップへ戻る」ボタンは言語ごとに表示を切り替え、英語とベトナム語は単語単位で縦に配置。

### UI・コード整理

- 既存のカード、詳細画面、出勤グラフ、ステータス表示のデザインと操作領域を維持。
- 未使用の従業員表示モジュール、未使用のフォーマット関数、重複した翻訳上書き、旧権限案内を整理。
- Employee API Hook、Mock データ、ページ単位の読み込み構成を維持し、今回の整理では画面仕様を変更していない。

## 今回の範囲と制約

- 今回はフロントエンドの機能ロジック、表示、Mock データ検証を中心とした段階版である。
- API の本番接続、認証、ロール別の最終権限は後続の統合工程で確認する。
- 勤務時間の表示と警告は店舗のシフト管理を補助するものであり、法的判断そのものを自動化するものではない。
