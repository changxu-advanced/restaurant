# v0.4.0｜店长聊天与协作消息

**日期：2026-10-29**

## 中文说明

本阶段完成店长端聊天协作功能，并将聊天页面整理为可继续接入后端 REST API 的前端 Mock 版本。

### 功能范围

- 群聊时间线：普通消息、日期分隔、当前登录角色消息靠右、其他成员消息靠左。
- 店长操作：发起缺员支援、发布问题、发布全体通知、搜索聊天记录。
- 支援卡片：员工可分别选择“支援できます／一部時間なら可能／无法支援”，每张卡片独立保存回复状态；店长点击卡片后可在蒙层中按同意、部分同意、不同意查看回复汇总和人员名单。
- 问题卡片：店长和员工均可解决或重新打开问题，解决者和处理时间同步保留在 Mock 数据中。
- 消息操作：普通文字消息支持复制和回复；图片、PDF 消息只显示回复；复制后显示“✓ 已复制”，两秒内渐隐关闭。
- 附件消息：支持最多 5 个照片或 PDF，支持选择、拖拽、缩略图、全屏预览和 PDF 只读查看；聊天搜索支持按关键词、照片和 PDF 类型筛选并跳转到原消息。
- 支援表单：日期不能早于今天，结束时间不能早于开始时间；时间、岗位、回复期限使用统一表单样式和多语言文案。

### 数据与接口

- Mock 数据继续保存在 `localStorage`，刷新页面和切换角色后保留聊天记录、附件元数据、问题状态和支援回复。
- 保留 `/api/v1/chat/messages`、`/api/v1/chat/support-requests`、`/api/v1/chat/issues` 及回复、解决、重新打开接口约定。
- 页面组件只通过聊天 API Hook 访问数据，后端完成后可切换数据源而不改变主要交互。

### 代码整理

- 删除聊天 Mock 中未使用的分项列表函数和员工 Mock 中重复的预警辅助函数。
- 统一聊天展示、附件筛选、角色判断、支援回复状态和多语言映射。
- 增加聊天搜索、角色切换、附件类型和支援回复独立性的回归测试。

### 已知边界

- 当前仍为前端 Mock，跨设备同步、真实权限、并发回复和附件持久化需要后端数据库与对象存储支持。
- 员工回复界面使用演示身份，正式环境需要替换为登录用户身份并由服务端校验权限。

## 日本語説明

本段階では店長向けのチャット協業機能を完成させ、後続の REST API 接続に切り替えられるフロントエンド Mock 構成として整理した。

### 機能範囲

- グループチャットのタイムライン、日付区切り、現在のログイン役割を右側に表示する LINE 風のメッセージ配置。
- 店長による欠員支援の作成、問題投稿、全体通知、チャット履歴検索。
- 欠員支援カードごとに「支援可能・一部時間なら可能・支援不可」を独立保存し、店長がカードをクリックすると回答状況を同意・一部同意・不同意に分けて確認できるモーダル。
- 問題カードは店長とスタッフの双方が解決・再開でき、対応者と対応時刻を保持する。
- 通常の文字メッセージはコピーと返信、画像・PDF メッセージは返信のみ。コピー後は「✓ コピーしました」を表示し、2 秒以内にフェードアウトする。
- 最大 5 件の画像または PDF の添付、ドラッグ＆ドロップ、サムネイル、全画面プレビュー、PDF の読み取り専用表示に対応。キーワード・画像・PDF で検索して元のメッセージへ移動できる。
- 欠員支援フォームは今日より前の日付を禁止し、終了時刻が開始時刻より前にならないよう検証する。

### データと API

- Mock データは `localStorage` に保存し、更新、役割切り替え後もメッセージ、添付ファイル、問題状態、支援回答を保持する。
- `/api/v1/chat/messages`、`/api/v1/chat/support-requests`、`/api/v1/chat/issues` と回答・解決・再開 API の契約を維持する。
- UI はチャット API Hook 経由でデータを取得するため、バックエンド実装後も画面の主要な操作を変更せずに接続先を切り替えられる。

### コード整理

- 未使用だったチャット Mock の一覧関数と、重複していた従業員 Mock の警告ヘルパーを削除した。
- チャット表示、添付ファイル検索、役割判定、支援回答状態、多言語表示を整理した。
- チャット検索、役割切り替え、添付ファイル種別、支援回答の独立性に関する回帰テストを追加した。

### 既知の制限

- 現段階はフロントエンド Mock のため、複数端末同期、実際の権限、同時更新、添付ファイルの永続化にはバックエンド DB とオブジェクトストレージが必要である。
- スタッフ回答はデモ用ユーザーを使用している。正式版ではログインユーザーとサーバー側の権限検証に置き換える。
