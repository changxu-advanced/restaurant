# v0.2.0｜异常运营、排班增强与多语言基础

**日期：2026-10-23**

## 中文说明

在基础运营系统上增加客诉、预约、设备维护、过敏原确认、跨店支援和员工评价等异常运营模块；增加小时级可用时间、时间范围选择和范围取消；完成六种界面的多语言基础整理。

本阶段仍未包含完整员工档案管理。员工合同、工时规则、休职/复职和员工详情属于 v0.3.0。

## 日本語説明

基盤版に、顧客対応、予約、設備保全、アレルゲン確認、他店舗支援、従業員評価などの例外運用機能を追加した。時間単位の勤務可能時間、範囲選択、範囲キャンセルにも対応し、6言語の画面基盤を整備した。

正式な従業員台帳、契約勤務時間、休職・復職、従業員詳細は v0.3.0 で追加する。
