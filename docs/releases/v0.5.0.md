# v0.5.0｜营业额可视化与已完成排班表 PDF 导出

**日期：2026-10-30**

## 中文说明

本阶段在 v0.4.0 店长聊天与协作功能的基础上，完成日结页面的数据可视化，并统一了已完成排班表的导出入口。

### 功能范围

- 当日营业额主指标：首屏突出显示当天营业额、POS 同步时间和较昨日变化。
- 最近 7 天营业额波浪折线图：显示日期、Y 轴金额刻度，数据点在进入视口后从底部展开并落到最终值。
- 支付方式圆环图：区分现金与移动支付比例；悬停时显示具体金额，区域轻微错开，圆心比例保持不变。
- 经营辅助指标：交易笔数、客单价、峰值时间带、销售额最高日期，以及毛利、人件费和现金差额。
- 设置页和排班页统一提供“导出已完成排班表 PDF”。导出内容使用甘特图：横轴时间、纵轴员工、色块表示班次、纹理标识需要注意的班次。
- PDF 保留门店信息、营业时间、排班期间、生成时间、下载人员、追踪 ID 和可追溯水印。
- 页面继续支持六种界面语言，图表、指标、按钮和 PDF 打印视图随当前语言切换。

### 数据与接口

- 本阶段仍使用前端 Mock 数据和 localStorage，未新增后端 API 或数据库表。
- 日结页面的动画、图表和导出逻辑均在前端完成；后续接入真实营业数据时可替换数据源，不改变展示结构。
- 运行网页 Demo 时不需要启动 API 或数据库；需要验证完整 Java API、Scheduler 和基础设施时再按 README 启动 Docker 服务。

### 本地运行

```bash
git clone https://github.com/changxu-advanced/restaurant.git
cd restaurant
pnpm install
pnpm dev
```

打开 `http://localhost:5173` 即可查看前端 Demo。环境要求：Node.js 22、pnpm 11；后端联调另需 Docker Desktop。

### 验证结果

- Web TypeScript 类型检查通过。
- Web Vitest：57 tests passed。
- Web production build 通过。
- `git diff --check` 通过。

### 已知边界

- 营业额、支付方式和排班数据仍是演示数据，不代表真实财务记录。
- PDF 当前通过浏览器打印视图生成；正式环境可替换为服务端 PDF 生成并由后端记录下载审计。

## 日本語説明

本段階では v0.4.0 の店長向けチャット協業機能を維持しながら、日次締め画面の可視化と完成シフト表 PDF 出力を追加した。

### 機能範囲

- 当日の売上を最初に表示し、POS 同期時刻と前日比を確認できる。
- 直近 7 日間の売上を波形の折れ線グラフで表示する。Y 軸の金額目盛り、日付、視界に入った時の展開アニメーションを備える。
- 支払方法のドーナツグラフで現金とキャッシュレスの比率を表示し、ホバー時に金額を確認できる。
- 取引件数、客単価、ピーク時間帯、売上トップ日、粗利、人件費、現金差額を表示する。
- 設定画面とシフト画面の出力ボタンを「完成したシフト表をPDF出力」に統一した。PDF は時間軸とスタッフ軸を持つガントチャート形式で生成される。
- 店舗情報、営業時間、対象期間、生成日時、ダウンロード者、追跡 ID、透かしを PDF に記録する。
- 6 言語の切り替えに対応し、グラフ、指標、ボタン、PDF 印刷画面も現在の言語に合わせて表示する。

### データと API

- 本段階は引き続きフロントエンド Mock と localStorage を使用し、バックエンド API や DB テーブルは変更していない。
- 売上・支払方法・シフトデータはデモ用であり、後で実データ API に差し替えられる構成にしている。
- 画面確認だけなら API や DB を起動せず、README の `pnpm dev` だけで実行できる。

### ローカル実行

```bash
git clone https://github.com/changxu-advanced/restaurant.git
cd restaurant
pnpm install
pnpm dev
```

`http://localhost:5173` を開くとフロントエンド Demo を確認できる。Node.js 22 と pnpm 11 が必要。バックエンド連携を確認する場合は Docker Desktop も使用する。

### 既知の制限

- 売上、支払方法、シフトは架空データである。
- PDF はブラウザの印刷画面から保存する方式で、サーバー側の監査保存は今後の対応となる。
