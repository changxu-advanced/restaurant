# v0.1.0｜基础餐饮运营系统

**日期：2026-10-22**

## 中文说明

首个可运行阶段，建立餐饮门店运营系统的基础结构：运营看板、库存、交接、结算、排班、Spring Boot API、Python Scheduler、Docker 和 AWS CDK 基础设施。

本阶段同时提供日语、简体中文和英语基础界面，并保留本地开发、测试和 CI 配置。员工管理仍属于基础占位能力，尚未进入正式员工档案流程。

## 日本語説明

飲食店向けオンライン運用システムの初期版。運用ダッシュボード、在庫、引き継ぎ、締め処理、シフト、Spring Boot API、Python Scheduler、Docker、AWS CDK の基盤を追加した。

日本語・簡体字中国語・英語の基本画面を用意し、ローカル開発、テスト、CI 構成も整備した。従業員管理はまだ基盤段階であり、正式な従業員台帳機能は次の段階で追加する。
