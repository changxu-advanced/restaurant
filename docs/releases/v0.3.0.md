# v0.3.0｜员工管理系统

**日期：2026-10-28**

## 中文说明

本阶段完成员工管理系统：员工列表、搜索、在籍状态筛选、详情、编辑、自动保存、合同工时、技能培训、希望时间段和周一至周日出勤图表。

工时规则区分正社员、特定技能、普通兼职和留学生；留学生严格计算每周 28/40 小时及兼业合计；普通兼职使用店内合同参考；休职显示当前无出勤；退职保留历史记录但不参与当前工时判断。

同时加入 36 名边界 Mock 员工、六种语言的岗位技能转换、休职/复职流程、标签回归测试和阶段性中日说明文件。

## 日本語説明

本段階で従業員管理システムを完成させた。従業員一覧、検索、在籍状態フィルター、詳細、編集、自動保存、契約勤務時間、スキル・研修、希望時間帯、月曜日から日曜日までの出勤グラフを追加した。

正社員、特定技能、一般アルバイト、留学生アルバイトで勤務時間ルールを分離。留学生は週28時間・長期休暇40時間と兼業時間を厳格に合算し、一般アルバイトは店舗契約参考時間を使用する。休職者は現在の出勤なし、退職者は過去記録を残しながら現在の勤務時間判定から除外する。

36名の境界条件 Mock、6言語の職種・スキル表示、休職・復職フロー、表示マッピングの回帰テスト、段階説明書も追加した。
